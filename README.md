# Sistema de Rutas Inteligente

## Descripción
Este proyecto permite encontrar la mejor ruta entre estaciones de un sistema de transporte.

## Tecnologías
- Python

## Funcionamiento
El sistema utiliza:
- Reglas lógicas (evitar estaciones)
- Algoritmo A* para encontrar rutas óptimas

## Ejemplo 1
Entrada:
D → A

Salida:
D → C → A  
Costo: 5

## Ejemplo 2
Entrada:
F → B

Salida:
F → D → B  
Costo: 12
