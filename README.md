# Sistema de Rutas Inteligente

## Descripción
Este proyecto permite encontrar la mejor ruta entre dos estaciones dentro de un sistema de transporte.

El sistema utiliza reglas lógicas y un algoritmo de búsqueda para determinar el camino más óptimo.

---

## Tecnologías utilizadas
- Python

---

## Funcionamiento

El sistema:
- Representa estaciones como nodos
- Usa costos entre estaciones
- Aplica una regla para evitar estaciones restringidas
- Calcula la mejor ruta posible

---

## Ejemplos de uso

### Ejemplo 1
Entrada:
D → A

Salida:
D → C → A  
Costo total: 5

---

### Ejemplo 2
Entrada:
F → B

Salida:
F → D → B  
Costo total: 12

---

## Regla implementada
El sistema evita la estación E, por lo que no será utilizada en las rutas.
